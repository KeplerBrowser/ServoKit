# Development

[AGENTS.md](../../../AGENTS.md) owns approval and delivery rules;
[CONTRIBUTING.md](../../../CONTRIBUTING.md) describes RFC discussion and acceptance.
Read only the reference for the assigned phase:

- [Implementation](references/implementation.md): deliver and validate approved scope.
- [Review](references/review.md): assess a design or implementation independently.
- [Pull request](references/pull-request.md): submit, address feedback, and merge.

When delegating, pass the relevant phase reference, scope, affected files, and
stopping point. For RFC review, include the proposal and discussion. For
implementation review, include the approved scope, revision, comparison base,
and validation evidence.
