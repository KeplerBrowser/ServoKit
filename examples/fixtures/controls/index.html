Servokit cross-host fixture

Embedder-control fixtures ready

These host-neutral pages exercise browser controls that are usually resolved by the embedding host: dialogs, text input and IME, select controls, picker inputs, file inputs, permissions, and context-menu targets. They use static HTML, CSS, and inline JavaScript only.

Control fixture pages

Dialogs Text input and IME Select elements Non-text pickers File input Permissions Context-menu targets

Coverage map

  • Dialogs trigger alert(), confirm(), and prompt() so a host can present and resolve simple JavaScript dialogs.
  • Text input and IME includes common text input modes, multiline text, contenteditable text, and lower-page fields for keyboard/viewport checks.
  • Select elements includes basic, grouped, disabled, preselected, and multiple-select controls.
  • Non-text pickers includes color, date, time, datetime-local, month, week, number, range, and checkbox/radio controls.
  • File input includes single, multiple, image-filtered, and capture-hinted file controls.
  • Permissions triggers notification, geolocation, camera, and microphone requests when the browser and serving context support them.
  • Context-menu targets provides links, selectable text, images, editable fields, and generic blocks for long-press or right-click checks.
Expected host signal: each page loads successfully, the host logs the corresponding control request when implemented, and unsupported controls report unavailable/unsupported without crashing the webview.
